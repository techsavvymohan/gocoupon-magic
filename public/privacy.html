1. Overview & Single Purpose Statement

This Privacy Policy governs the GoCoupon – Coupon Finder browser extension (ID: bbdcjoadldgankjdhdlmncacpkengnid) and the gocoupon.io web platform. GoCoupon is committed to consumer transparency, data minimization, and strict compliance with the Google Chrome Web Store Developer Program Policies, the Chrome Web Store User Data FAQ, and the Limited Use Requirements.

Single Purpose Statement

GoCoupon has a single, narrow purpose: automatically finding, testing, and applying promotional discount coupon codes and comparing product prices at checkout on supported online retail stores to save consumers money.

2. User Data Collection & Access

In accordance with Chrome Web Store Minimal Data requirements, GoCoupon accesses and collects only the technical data strictly necessary to execute coupon testing:

2.1 Data Categories We Access or Collect:

  1. Shopping URLs and Merchant Domains (Web History / Scoped URLs):
    What is accessed: When you navigate to a supported e-commerce store (e.g., Amazon, Flipkart, Myntra, Meesho, Tata CLiQ, Croma, Reliance Digital, Walmart, Target, Best Buy), the extension detects the merchant hostname and checkout path to verify if coupon codes exist for that retailer.
    Scope: GoCoupon never tracks, logs, or inspects broad web browsing history across non-supported or non-shopping websites.
  2. Website Content & Checkout Form Fields (Website Content):
    What is accessed: On checkout pages, our sandboxed content scripts locate the discount/coupon code input box and the order total element to test candidate coupons and calculate savings.
    Scope: GoCoupon only interacts with coupon input fields and order total numbers. We never read, capture, or inspect private cart items, personal customer details, or shipping addresses.
  3. Coupon Telemetry & Anonymized Savings Results (User Activity):
    What is collected: When coupon codes are auto-applied, the extension transmits anonymous performance telemetry: the merchant name, the coupon code tested, whether it succeeded or failed, and the discount amount. Telemetry includes a cryptographic one-way hash of the checkout domain (page_url_hash). This contains zero personal identifiers.
  4. Local Extension Preferences (Local Storage):
    What is collected: User interface preferences (e.g., sound toggles, auto-apply preferences, recent store cache) stored locally on your device via chrome.storage.local.
  5. Affiliate Click Audit Records (User-Initiated Action):
    What is collected: If and only when a user explicitly clicks the “Activate Cash Back Bonus” button, an audit log containing the merchant identifier, affiliate network tag, and timestamp is recorded to ensure compliance with merchant operating agreements.

2.2 Data We NEVER Collect (Zero-Access Guarantee):

  • NO Personally Identifiable Information (PII): No names, email addresses, phone numbers, home addresses, government IDs, or age.
  • NO Financial or Payment Data: We never read, touch, log, or transmit credit/debit card numbers, CVVs, expiration dates, UPI PINs, bank accounts, or billing information. All checkout transactions occur directly and securely on the merchant's platform.
  • NO Passwords or Authentication Data: We never access passwords, session cookies, login credentials, or two-factor authentication (2FA/OTP) tokens.
  • NO Keystroke Logging: We do not track general keyboard input. Script interaction is strictly limited to injecting coupon strings into merchant promo code boxes.
  • NO General Browsing Monitoring: Search queries, private emails, social media, and web browsing on non-shopping websites are completely inaccessible and invisible to GoCoupon.

3. User Data Handling & Processing

GoCoupon processes accessed data strictly under the following rules and Chrome Web Store requirements:

  • Purpose Limitation (Single Purpose): All data handling is confined exclusively to retrieving verified promo codes, testing them in parallel on merchant forms, and applying the code with the highest dollar savings.
  • Local Client-Side Processing & Offline Resilience: Coupon injection and testing occur locally within your active browser tab through sandboxed content scripts. The extension is designed to operate locally using cached data even when offline or disconnected from our API.
  • No User Profiling: We do not build personal behavioral profiles, cross-device graphs, or device fingerprints.
  • Fair & Unbiased Algorithm: The coupon engine sorts and selects coupons strictly by highest calculated savings. Working non-affiliate codes are never deprioritized or replaced with lower-value affiliate codes.
  • Affirmative User Consent & Opt-Out (Purple Nickel): Affirmative user consent is established when you install and enable the extension. Users maintain complete control: you may opt out of anonymous coupon telemetry reporting at any time via the extension popup settings, or completely revoke consent and purge all data by uninstalling the extension.
  • Protection of Sensitive Categories (Purple Magnesium): In strict compliance with Chrome Web Store handling requirements, GoCoupon never publicly discloses or abuses sensitive data:
    • • Web Browsing Activity: Scoped strictly to verifying store URLs on supported merchant checkout pages solely to deliver our core coupon savings feature. General browsing history is never tracked, stored, or shared.
    • • Financial & Payment Data: Zero collection and zero disclosure. All transactions happen directly on merchant gateways.
    • • Authentication Information: Zero collection and zero disclosure. Passwords, session cookies, and login credentials are completely untouched.

9. Frequently Asked Privacy & Data Questions

Quick answers to the most common questions regarding GoCoupon's user data handling, security architecture, and Chrome Web Store policies:

What user data does the GoCoupon Chrome extension collect?

GoCoupon accesses shopping URLs on supported merchant domains to detect checkout pages, interacts with discount code input boxes to test coupons, and logs anonymous coupon success or failure telemetry with a cryptographic one-way domain hash. GoCoupon never collects personally identifiable information (PII), names, emails, phone numbers, passwords, or payment credentials.

Does GoCoupon sell, rent, or monetize my personal data?

No. GoCoupon maintains an absolute zero-sale policy. We never sell, rent, trade, or transfer personal user data, browsing histories, or shopping patterns to third-party data brokers or advertising networks under any circumstances.

How does GoCoupon securely transmit and store data?

All network queries to our backend database (hosted by Supabase Inc.) are encrypted in transit using modern cryptography over Transport Layer Security (TLS 1.3 / HTTPS). Data is never sent via unencrypted HTTP or encoded into URL query parameters.

How can I delete my data or revoke permissions from GoCoupon?

You can immediately delete all locally stored preferences and cached data by uninstalling the extension via chrome://extensions or clearing browser site data at chrome://settings/siteData. Since telemetry is strictly anonymous and has no user accounts, no personal identity is tied to our database.

Does GoCoupon comply with Google Chrome Web Store Limited Use policies?

Yes. GoCoupon fully complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data access is confined exclusively to providing prominent user-facing coupon auto-apply and price comparison features, with zero advertising transfers and strict human review restrictions.

How does GoCoupon earn revenue if it is 100% free for consumers?

GoCoupon is free for all users. When you complete a qualifying purchase after explicitly activating cash back or using an affiliate-supported coupon, retail affiliate networks (such as Amazon Associates or Cuelinks) may pay GoCoupon a small referral commission at zero additional cost to you.
